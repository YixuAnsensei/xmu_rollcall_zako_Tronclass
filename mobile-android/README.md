# zako 签到助手 Android 移动端工程 (Zako Rollcall Mobile)

专门针对厦门大学（XMU）畅课（Tronclass）数字签到与雷达签到打造的原生 Android 手机应用。

---

## 🌟 核心特色

1. **告别 PC 端 Playwright 依赖**
   - 移动端内嵌轻量原生 WebView，直接加载厦大 CAS 统一身份认证（ids.xmu.edu.cn）。
   - 用户输入账号密码登录后，系统自动拦截提取 Cookie 与学生 ID，自动持久化存储，无需每次输入。

2. **完整实现数字签到与一键提交**
   - 自动获取最新学期与已选课程列表。
   - 一键探测选中课程的最新签到信息，秒级抓取数字签到码并支持直接在线提交。

3. **完整移植四校区两阶段雷达签到引擎**
   - 内置厦大四大校区（思明校区、翔安校区、漳州校区、马来西亚分校）经纬度探针基准。
   - 第一阶段自动探测最近校区中心，第二阶段通过双正交偏移探针与两圆相交几何分析解算教师实际位置，自动完成雷达签到。

4. **GitHub Actions 云端自动编译 APK**
   - 无需在本地电脑配置繁重的 Android Studio、Android SDK 或 Java 环境变量。
   - 代码推送到 GitHub 后，云端流水线自动编译生成可安装的 `.apk` 文件。

---

## 📱 手机端操作流程

1. **登录系统**
   - 点击右上角「登录 Tronclass」，在弹出的官方登录页面输入学号密码。
   - 登录成功后会自动识别 Cookie 并跳转回主页面，显示「已连接厦大畅课喵❤」。

2. **选择课程**
   - 下拉菜单会自动加载当前学期所修的所有课程。
   - 选择你要签到的课程（支持点击「刷新课程」同步最新课表）。

3. **探测签到**
   - 点击「🔍 探测签到」，应用会自动查询该课程的最新签到记录。
   - 若有数字签到，会直接显示签到码（如 `【 6688 】`）与截止状态。
   - 若是雷达签到，状态栏会显示雷达活跃状态。

4. **一键签到**
   - 数字签到：点击「🐾 一键数字签到」，将提取到的签到码秒级回传畅课服务器。
   - 雷达签到：点击「🛰 一键雷达签到」，实时观测控制台探针输出与定位解算结果，直至提示成功。

## 🛠 云端构建与下载 APK 方式

1. 将本分支/目录推送到你的 GitHub 仓库。
2. 打开 GitHub 仓库页面，点击顶部的 **Actions** 标签栏。
3. 点击左侧的 **Build Android APK** 工作流，点击 **Run workflow**（或代码推送时会自动触发）。
4. 等待 2~3 分钟构建完成，在构建详情底部的 **Artifacts** 区域即可直接下载 `zako-rollcall-debug-apk.zip`。
5. 解压后将里面的 `.apk` 传到安卓手机上直接点击安装即可使用。

## 💻 本地编译方式（针对开发者）

若本地已安装 JDK 17 与 Android SDK：

```bash
cd mobile-android
./gradlew assembleDebug
```

生成文件位于：`mobile-android/app/build/outputs/apk/debug/app-debug.apk`
