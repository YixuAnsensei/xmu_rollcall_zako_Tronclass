开发调试（Expo Go）:
1. 手机和电脑连同一个 WiFi
2. 启动: bunx expo start --tunnel  (推荐, 免防火墙配置)
   或局域网模式需管理员放行:
   netsh advfirewall firewall add rule name="Expo DevServer 8082" protocol=TCP dir=in localport=8082 action=allow
3. Expo Go 扫终端二维码或输入 exp:// 地址
注意: CAS 登录依赖本地原生模块, Expo Go 无法测试, 需构建 APK 真机验证

自己构建 APK（构建在云端跑, 本机不需要 Android Studio）:
1. cd D:\claude-code-haha\xmu_rollcall_mobile
2. bunx eas-cli build --platform android --profile preview
3. 构建约 10-20 分钟, 完成后终端直接打印二维码和链接, 手机扫码即可安装
   （前提: 已登录 Expo 账号, 用 bunx eas-cli login; 项目已关联 eas.projectId）
